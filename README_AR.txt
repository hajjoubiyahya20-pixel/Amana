مشروع AMANA — ملف التشغيل

محتويات الملف:
- index.html : واجهة الموقع كاملة.
- style.css : التصميم المتجاوب للأجهزة والحواسيب.
- script.js : وظائف البحث والنشر والتقييم والإبلاغ والتواصل.
- config.js : إعدادات Supabase.

طريقة التشغيل على Windows 10:
1) فك ضغط AMANA_Project.zip في مجلد على الحاسوب.
2) افتح المجلد في VS Code.
3) افتح Terminal من VS Code.
4) إذا كان Python مثبتاً، نفّذ:
   python -m http.server 5500
5) افتح المتصفح على:
   http://localhost:5500

مهم:
- يجب أن يكون الاتصال بالإنترنت متاحاً لأن الخدمات والصور محفوظة في Supabase.
- لا تفتح index.html بالنقر المزدوج (file://). شغّله عبر localhost.
- المشروع يستخدم Supabase JS من CDN.
- ملف config.js يحتوي Publishable key فقط. لا تضع Secret key أو service_role key فيه.
- يجب أن يكون اسم Storage bucket هو amana-images.
- يعتمد الموقع على الجداول الموجودة: services, reviews, reports، وعلى أعمدة الخدمات التي أُنشئت سابقاً.
- يجب تفعيل Anonymous Sign-ins في Supabase Auth.
- التصميم يدعم العربية والفرنسية والإنجليزية. البحث الحالي يستخدم مطابقة كلمات ومفردات مترادفة شائعة بين اللغات، وليس ترجمة آلية كاملة. الترجمة الآلية الحقيقية تحتاج خدمة ترجمة خارجية ومفتاح API محفوظ على الخادم.
- اختيار مشاركة الموقع الدقيق منفصل عن طلب تحديد الموقع. لا يُحفظ الموقع في السجل إلا عند تفعيل خيار الموافقة.
- في هذه النسخة، يجب تفعيل موافقة نشر بيانات التواصل حتى تظهر تفاصيل الاتصال للباحثين.
- الصور تُرفع إلى bucket باسم amana-images، وتُعرض عبر رابط عام.
- لا يوجد ضمان خلو أي مشروع برمجي من الأخطاء؛ اختبر النشر والبحث والتقييم على بيانات تجريبية أولاً.

تنبيه قاعدة البيانات:
هذه النسخة تتوافق مع المخطط الذي أنشأته سابقاً. في ذلك المخطط بيانات الهاتف والبريد والإحداثيات موجودة في جدول services الذي يقرأه الزوار. لا تنشر بيانات حقيقية قبل مراجعة سياسات الوصول وحماية هذه الحقول.


إدارة الخدمات وحذفها:
- اضغط زر "خدماتي" في أعلى الموقع لعرض الخدمات التي نشرتها من هذا المتصفح.
- اضغط "حذف الخدمة" بجانب الخدمة، ثم أكد الحذف.
- لأن AMANA يستخدم جلسة مجهولة، فإن قائمة خدماتك مرتبطة ببيانات المتصفح نفسه. إذا حذفت بيانات المتصفح أو استخدمت جهازاً/متصفحاً آخر، فلن تتمكن تلقائياً من الوصول إلى الخدمات المنشورة من الجلسة القديمة.


مهم قبل استخدام زر حذف الخدمة:
1. افتح Supabase ثم SQL Editor ثم New query.
2. افتح الملف DELETE_POLICIES.sql وانسخ محتواه إلى المحرر.
3. اضغط Run مرة واحدة.
هذا يسمح لصاحب الخدمة بحذف التقييمات والبلاغات المرتبطة بخدمته عند حذفها.


إصلاح التقييمات وإظهارها للجميع:
1. افتح Supabase ثم SQL Editor ثم New query.
2. افتح REVIEWS_POLICIES.sql وانسخ محتواه.
3. اضغط Run مرة واحدة.
4. استبدل ملفات المشروع بالنسخة الجديدة وشغّل الموقع.
- يمكن لكل زائر رؤية متوسط النجوم وعدد التقييمات والتعليقات المنشورة.
- يمكن للمستخدم المسجل بجلسة مجهولة إضافة تقييم واحد لكل خدمة.
- لا يمكن لصاحب الخدمة تقييم خدمته بنفسه.
